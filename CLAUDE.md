# Example names

When placeholders, hints, docs or comments need a generic person's name (an input's "e.g. …", a sample share page title), use women's names: Katie, Samantha, and the like.

# Tests

`npm test` runs the Playwright tests in `e2e/` (see the README's "Tests"). Run them after changing adding, searching, saving, editing or deleting books, and add a test for any new common action or a bug they missed.
